ABC Dry Chemical Powder Extinguisher

Multi-purpose extinguisher suitable for Class A (solid combustibles), Class B (flammable liquids), and Class C (flammable gases) fires. Operates using MAP-based dry chemical powder with rapid flame knock-down capability.

Key Pointers

  • Multi-purpose fire extinguisher suitable for Class A, B, and C fires

  • Provides rapid flame knock-down for quick fire control
